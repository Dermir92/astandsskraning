[Umsóknir og eyðublöð - HMS on Ísland.is](https://island.is/s/hms/umsoknir-og-eydublod). The web text fetch returned 403, but ordinary public HTTP retrieval succeeded. Its actual HTML links were inspected and retained locally. This index currently links H1 and H2 below. An accessible link is evidence of publication, not proof that every sentence is current law.

### H1 - Current index-linked residential lease

[HÚSALEIGUSAMNINGUR UM ÍBÚÐARHÚSNÆÐI - Leigusamningur.pdf](https://assets.ctfassets.net/8k0h54kbe6bj/28hOipmGJso6ylesdW3fxJ/df32d6e7412f728cc64e836a84796477/Leigusamningur.pdf).

Nine physical/printed pages. Relevant sections: **1 parties and representatives (p. 1); 2 property description (pp. 1-2); 4 condition (p. 3); 6 meter numbers/readings/dates (p. 4); 12.A condition inspection and 12.B fire protection (pp. 7-8); assessment legend and party remarks (p. 8); lease signatures/witness fields (p. 9).** PDF creation metadata 5 September 2024; modification metadata 12 February 2026. These are file metadata, not official effective dates.

### H2 - Current index-linked condition/fire extract

Index label: **Yfirlýsing á úttekt á íbúðarhúsnæði**. Actual document begins **12. Úttekt á leiguhúsnæði**: [Ástands- og brunaúttekt extract](https://assets.ctfassets.net/8k0h54kbe6bj/4S3WMgj9WSR1lVXBrM64Wd/d8579f595f2597f6610ce75bbc6a1c94/_stands_og_bruna_ttekt_1sept2024.pdf).

**Three physical pages, printed 7/9, 8/9 and 9/9.** These are lease-template extracts, not a self-contained modern inspection declaration with its own property/lease header. Section 12.A has a findings box and room/fixture grid; the table is expressly optional if principal results are supplied. The next page contains separate inspector/party remarks, fire questions and A-G assessment legend. The final page contains lease execution language, spouse/witness fields and registration wording. Filename refers to 1 September 2024; PDF creation/modification metadata is 10 October 2024. All three pages were visually inspected after rasterization because text extraction contains damaged character mappings.

### H3 - Older official detail-page declaration

[HMS detail page: Yfirlýsing um úttekt á íbúðarhúsnæði](https://hms.is/umsoknir-og-eydublod/yfirlysing-um-uttekt-a-ibu%C3%B0arhusn%C3%A6%C3%B0i) still links a different [two-page declaration](https://assets.ctfassets.net/8k0h54kbe6bj/4S3WMgj9WSR1lVXBrM64Wd/a94391333486eb09d1c83ea69e19c12a/Yfirlysing_um_uttekt_a_ibudarhusnaedi_FORMID__1_.pdf).

It includes property and lease identification, parties, a room/fixture grid, separate remarks, inspection place/date/time, signatures and three-copy wording. Its metadata indicates December 2018. Both pages were visually inspected. It is an official hosted document, but **not verified as the preferred current form** given the conflicting index link. It lacks the separate fire section visible in H1/H2. Do not silently combine the two and call the result an HMS checklist.

### Publication inconsistencies requiring caution

- H1 and H2 still contain a registration footnote restricted to professional landlords. L5's 2026 duty is broader. The Act and commencement rule prevail.
- H1/H2/H3 reference Chapter XVI in a sentence about inspection evidence; the current inspection chapter is XIV. Do not copy that cross-reference.
- H2's detector question retains an area-based shorthand; see R1/R2 below for the amended regulatory text and distinct building guidance.
- H2's lease-signature and two-copy language is not a replacement for L1 Art. 72's inspection-declaration provisions. Spouse/witness fields concern that lease form; this audit does not make them compulsory fields in a standalone condition report.
- A search-indexed [older nine-page HMS lease](https://assets.ctfassets.net/8k0h54kbe6bj/28hOipmGJso6ylesdW3fxJ/64cc1ac6471d863ce03ac9ad0091dc07/Leigusamningur_HMS_lagf_C3_83_r_C3_83_ur_3.pdf) was retained only to distinguish it from H1. H1 is the current index target.

**Conclusion on availability:** an official current-linked condition/fire extract and a current-linked lease were verified. A separate, clearly versioned, current standalone HMS inspection declaration was **not** verified. HMS should clarify H2 versus H3 and the dated wording. No approved grading conversion, software certification, mandatory use of this particular form, or HMS endorsement was established.
