These PNGs are unmodified browser viewport screenshots. No cropping, resampling or annotation was applied. SHA-256 hashes and encoded dimensions are in the summary. The photographs were generated by test canvas code and visibly say “Synthetic inspection image”; they depict no real property or person. Images contain no EXIF or textual metadata.

The final `tests/inspection-evidence.spec.ts` capture test verifies nine states at each of 320, 360, 390, 768 and 1440 px: empty/populated editor, editor at 200% text, removal confirmation, retained text, review, preview, preview at 200% text, and review at 200% text. It produces 45 full-page captures and 20 viewport captures. Screenshots were visually inspected separately from automated assertions. This is automated Chromium browser verification and visual inspection, not a physical-device or manual screen-reader session.

The full test suite also uses desktop 1440 × 1000, mobile 360 × 800 and mobile 390 × 844 projects. Duplicate matrix cases intentionally skip in the two mobile projects because the desktop case creates its own five isolated contexts. The existing intermediate-width test likewise runs only once in desktop.

To reproduce against production, run `npm run build`, start `npm run start` in another terminal, then run `npm test`. The default Playwright configuration reuses the existing localhost production server when `CI` is unset. For only the evidence flow, use `npx playwright test tests/inspection-evidence.spec.ts`; captures are written to ignored `artifacts/phase-1b2c/screenshots/`. This acceptance run used an ignored configuration override on a separate local port, with the same three projects and unchanged test assertions.

Full logs, traces, results JSON, HTML report and all 65 screenshots are retained locally under ignored `artifacts/phase-1b2c/`. Physical iPhone camera/library behavior, HEIC compatibility/conversion, Safari/Firefox, manual screen-reader testing and permanent photograph storage remain outside the delivered verification.
